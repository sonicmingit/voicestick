# VoiceStick 0.4.3：按键脚本、识别服务快速切换与连接修复

本版发布 Windows x64 中文客户端及 StickS3 配套固件。新增连续快捷键脚本，并把识别服务切换放到托盘第一层菜单。原有设置、API 密钥、豆包音频通道及按键预设继续使用。

## 按键脚本

在“设置 → 按键与快捷键…”中，为任一手势选择“快捷键脚本…”，点击“编辑…”。例如全选后复制：

```text
Ctrl+A
Wait:100
Ctrl+C
```

也可填写为 `Ctrl+A; Wait:100; Ctrl+C`，编辑器提供“全选后复制示例”。每一步支持现有的快捷键写法或 `Wait:毫秒`；最多 32 步，单次等待 1–5000 毫秒，累计等待不超过 10000 毫秒。脚本可以随按键预设保存。

脚本在触发时的前台窗口依次执行，等待期间不阻塞客户端。切换前台窗口、开始录音、取消识别、修改配置或设备连接变化时停止后续步骤；已完成的操作不会自动撤销。脚本运行期间不会叠加新的普通编辑动作。编辑后先在按键窗口点“确定”，再在外层设置点“保存”。

## 快速切换识别服务

托盘第一层新增“识别服务：当前服务”，可直接选择豆包输入法（测试）、火山引擎 API 或 VoiceStick Cloud API。切换立即生效并保存，沿用该服务已有配置，无需反复填写密钥或音频通道。

首次使用服务时仍需完成设置。API 模式需要对应的 API Key；豆包需要可用的 VB-CABLE 通道，输出为当前输入框、原文。切换会结束正在进行的录音／识别，丢弃尚未填入的结果，并停止快捷键脚本。

## 连接与提示修复

- Windows 客户端连接时同时重新初始化状态与音频通知，处理 HID 保持蓝牙连接时音频订阅未恢复、长按无法启动录音的问题。
- 切换识别服务时清理旧识别会话和设备录音状态，重新同步按键配置。
- 修正多行脚本保存时的换行转义，脚本及预设可以完整保存、重新载入。
- 修正设备语音键失败和超时提示，不再直接将“蓝牙键盘通道未就绪”归为“未配对”。已配对但键盘通道异常时，可先重新连接设备；必要时由管理员重新初始化该 VS 设备对应的 HID 键盘通道，保留现有配对。

## 安装、固件与验证

从托盘退出旧客户端后安装 MSI，或完整解压便携 ZIP 后运行 `VoiceStick.exe`。原有 `%APPDATA%\VoiceStick\config.toml` 继续使用，安装包不包含 API 密钥。此中文定制版关闭官方客户端自动更新，安装包未签名。

本版固件沿用 0.4.2 的手势、HID 语音快捷键、睡眠设置及屏幕版本显示功能，重新构建为 0.4.3，保持客户端与发布固件版本一致。已有正常工作的手势／HID 固件无需为了按键脚本或菜单切换重新刷机。首次安装、需要 HID 功能或希望统一版本时，可使用本版配套固件；OTA 镜像仅用于应用 OTA，USB 合并镜像写入偏移 `0x0`。

Windows 的 5 项自动测试覆盖脚本解析及限制、配置／预设保存、脚本定时执行和中止、录音互斥、服务切换、原有会话及输入法流程。2026-10-21 已在本机 VS-5614 上实测 API 长按录音、识别与填入；针对已配对但 HID 通道未恢复的状态，重新初始化设备键盘通道后，豆包语音键按下／释放均返回成功，会话正常结束，用户确认恢复。上述实测使用原有 HID 开发固件；重新构建的 0.4.3 镜像另行通过构建校验，不将其等同于已刷写真机验证。豆包出字准确度、音频首尾完整性和长期稳定性仍需继续验证。

详细教程：[自定义按键使用说明](https://github.com/sonicmingit/voicestick/blob/windows-v0.4.3/docs/自定义按键使用说明.md)、[豆包输入法使用说明](https://github.com/sonicmingit/voicestick/blob/windows-v0.4.3/docs/豆包输入法使用说明.md)。
