# VoiceStick Windows 中文定制版

适用于 Windows x64。0.4.0 主要界面已汉化，新增六个可自定义手势。配套 StickS3 0.4.0 固件支持主键、侧键各自的单击、双击和长按；旧固件保持原先的侧键发送方式。

新版设置与固件升级方法见 [自定义按键使用说明](自定义按键使用说明.md)。默认主键单击确认发送、长按录音；侧键单击撤销、双击重做、长按粘贴。文字填入后不再弹成功提示。

2026-10-19 已完成配套固件刷写、蓝牙版本／能力读取及按键配置同步，用户实际测试反馈「测试没问题」。详细变更、自动测试和 USB 识别问题记录见 [开发日志](开发日志.md)。实际按键以已保存的自定义配置为准。

## 安装与使用

1. 退出正在运行的旧版 VoiceStick，再运行 MSI 安装包。也可以解压便携版 ZIP，运行其中的 `VoiceStick.exe`。
2. 配对设备并配置语音识别服务。原有 `%APPDATA%\VoiceStick\config.toml` 会继续使用，安装包不包含 API 密钥。
3. 用主键长按录音，完成识别后文字直接填入当前输入框，不再等待 1.2 秒，也不会自动回车。
4. 可以先在输入框内修改文字，再单击同一设备的主键确认发送。目标应用需使用回车作为发送键。旧固件继续用侧键发送。

文字填入后立即收起悬浮窗，不显示输入完成提示。每次填入只允许确认一次；没有待发送文字时，确认发送不执行操作。开始新录音、断开设备或修改设置后，旧的待发送状态会清除。

切换到其他窗口时确认发送不会发送回车，请回到原输入窗口再确认。此检查以顶层窗口为单位，同一应用窗口内仍需保持正确输入框处于焦点。

填入失败会提示重试，并保留“恢复上次输入”入口。粘贴和回车采用 Windows 模拟按键，普通权限运行的程序不能向更高权限的应用注入按键。

## 设置

新固件在「设置 → 按键与快捷键…」配置，支持快捷键录制与命名预设。自定义按键开启且同步成功时，识别结果直接填入、不自动发送。托盘原有“按侧键确认发送”和录音模式用于旧固件或关闭自定义按键后的操作，对应 `side_button_send`、`interaction_mode` 与 `auto_enter`。

此本地定制版关闭了官方客户端自动更新，以保留汉化和自定义交互；设备固件更新功能仍可使用。安装包未使用原作者的签名证书签名。

## 重新构建

在已配置 MSVC x64、Windows SDK、CMake、Ninja、WiX 6 及 UI/Util 扩展的 PowerShell 环境中运行：

```powershell
scripts/build-windows-local.ps1
```

脚本先编译和运行核心测试，再生成 MSI、便携 ZIP 和 SHA-256 校验文件，输出到 `build/windows-local/`。`-ToolchainEnvironment` 可指定设置构建环境的 PowerShell 脚本，`-WinSparkleSource` 可指定已解压的 WinSparkle 0.9.2，`-WixPath` 可指定 WiX 路径。
