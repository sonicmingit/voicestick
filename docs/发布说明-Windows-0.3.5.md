# VoiceStick 0.3.5 Windows 中文定制版

Windows x64 客户端发布，无需更新 StickS3 固件。

## 更新内容

- 汉化托盘、设置、首次引导、设备配对、字幕及固件更新界面的主要文本。
- 默认使用“主键录音 → 识别后直接填入输入框 → 侧键回车发送”的交互，省去原来的 1.2 秒倒计时。
- 文字填入后可编辑；同一设备每次仅确认一次，提前或重复按侧键不会误发送。
- 增加发送状态提示、原窗口检查、剪贴板重试和粘贴失败恢复；切换窗口后可返回原输入窗口继续确认。
- 托盘和设置窗口均可关闭侧键发送，恢复原有交互；字幕模式保留原有行为。
- 增加本地构建脚本、第三方许可证说明和 SHA-256 校验文件，补充中文项目文档及 API 配置指南。

## 下载与安装

- `VoiceStick_0.3.5_zh-CN_side-send_x64.msi`：安装版。
- `VoiceStick_0.3.5_zh-CN_side-send_x64.zip`：解压后运行 `VoiceStick.exe`。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

安装前请退出旧版 VoiceStick。原有配置文件继续使用，包内不含 API 密钥。
这是未签名的定制构建，关闭了官方客户端自动更新以保留本地功能；设备固件更新仍可使用。
侧键模拟回车，目标应用需使用回车作为发送键。窗口检查以顶层窗口为单位，同一窗口内仍需保持目标输入框获得焦点。
