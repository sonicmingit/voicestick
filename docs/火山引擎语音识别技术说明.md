# 火山引擎 ASR 技术说明

本文仅保留与 Voice Stick 有关的火山引擎语音识别（ASR）技术细节。面向使用者的配置步骤和版本选择见 [API 配置指南](API配置与版本选择指南.md)。

## 接口地址

Voice Stick 使用优化版双向流式接口：

```text
wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async
```

火山引擎文档中的其他接口：

| 模式 | 接口地址 | 说明 |
| --- | --- | --- |
| 双向流式 | `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel` | 较早的流式接口路径。 |
| 流式输入 / 非流式结果 | `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_nostream` | 音频超过 15 秒或收到最后一个数据包后返回。 |
| 优化版双向流式 | `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async` | Voice Stick 优先使用，仅在识别结果变化时返回。 |

## 请求头

Voice Stick 使用新版控制台的鉴权方式：

| 请求头 | 值 |
| --- | --- |
| `X-Api-Key` | 从火山引擎新版控制台获取的 API Key。 |
| `X-Api-Resource-Id` | 资源 ID，例如 `volc.bigasr.sauc.duration`。 |
| `X-Api-Request-Id` | 当前 ASR 会话的 UUID。 |
| `X-Api-Sequence` | 建立 WebSocket 连接时为 `-1`。 |

WebSocket 响应头中的 `X-Tt-Logid` 可供火山引擎技术支持定位服务端问题。当前 Swift 客户端尚未将其展示出来。

## 资源 ID

| 模型 | 小时版资源 | 并发版资源 |
| --- | --- | --- |
| 豆包流式语音识别 1.0 | `volc.bigasr.sauc.duration` | `volc.bigasr.sauc.concurrent` |
| 豆包流式语音识别 2.0 | `volc.seedasr.sauc.duration` | `volc.seedasr.sauc.concurrent` |

## 首个请求的数据体

Voice Stick 发送 Ogg Opus 音频，因此客户端首个请求应使用：

```json
{
  "user": {
    "uid": "voice-stick-local"
  },
  "audio": {
    "format": "ogg",
    "codec": "opus",
    "rate": 16000,
    "bits": 16,
    "channel": 1
  },
  "request": {
    "model_name": "bigmodel",
    "enable_nonstream": true,
    "show_utterances": false,
    "enable_ddc": true
  }
}
```

`enable_nonstream = true` 会在优化版双向流式接口上启用二次识别模式：先快速返回中间文字，再使用非流式模型重新识别已完成的语音片段，以提高最终准确率。

## 音频数据包

火山引擎建议：

- 每个音频包时长为 100～200 ms。
- 发包间隔为 100～200 ms。
- 双向流式模式推荐使用 200 ms 音频包，以取得较好的性能。

StickS3 固件目前将音频编码为每包 60 ms 的 Opus 数据。macOS 应用将其封装为 Ogg Opus 数据块，本地录音达到 0.5 秒后开始转发。松开按键时，发送带有 WebSocket 二进制协议末包标记的最后一个 Ogg 数据块。

## 停顿与最终结果

`end_window_size` 是强制结束当前语音片段的静音阈值。

| 参数 | 含义 |
| --- | --- |
| `end_window_size` | 服务端结束当前语音片段并输出 `definite: true` 前等待的静音毫秒数。 |
| 默认值 | `800` ms。 |
| 最小值 | `200` ms。 |

当 `enable_nonstream = true` 时，火山引擎默认启用 VAD 分段。默认静音阈值为 800 ms，可通过 `end_window_size` 调整。

设置 `end_window_size` 后，火山引擎按静音时长决定该分段时机，不再依据语义分段。这适合希望更早收到 `definite: true` 的低延迟场景。

相关参数：

| 参数 | 含义 |
| --- | --- |
| `vad_segment_duration` | 语义分段静音阈值，默认 3000 ms，不决定何时出现 `definite: true`。设置 `end_window_size` 后此项不再生效。 |

Voice Stick 未在用户设置中提供 `end_window_size`，也未在 ASR 请求中发送该字段，因此使用服务端默认值。

## 客户端使用的响应字段

主要响应字段：

| 字段 | 含义 |
| --- | --- |
| `result.text` | 当前识别文字。 |
| `result.utterances[].definite` | 该片段是否已确定为最终结果。 |
| `result.utterances[].start_time` / `end_time` | 片段起止时间戳，单位为毫秒。 |

Voice Stick 在 ASR 活跃时显示中间文字，按键录音结束后，固件屏幕保持思考状态。最终文字在粘贴前进入 1.2 秒确认倒计时。主按键可暂停并再次确认粘贴；macOS 的侧键可取消正在识别或待确认的文字。Windows 默认侧键发送模式见 [Windows 侧键说明](../desktop/windows/Windows使用说明.md#侧键确认)。

## 常见错误码

| 错误码 | 含义 |
| --- | --- |
| `20000000` | 成功。 |
| `45000001` | 请求参数错误、缺少必填字段、字段值无效或重复请求。 |
| `45000002` | 音频为空。 |
| `45000081` | 等待数据包超时。 |
| `45000151` | 音频格式无效。 |
| `55000031` | 服务端繁忙。 |
