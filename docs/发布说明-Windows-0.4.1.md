# VoiceStick 0.4.1 Windows 中文定制版 + StickS3 固件

## 更新内容

- 托盘菜单顶部、托盘悬停提示和设置窗口标题显示客户端版本 `0.4.1`。
- 设置底部显示客户端版本和各个已连接设备的固件版本；设备连接、上报版本或断开时自动刷新。未连接时显示“未连接”，尚未上报时显示“读取中”。
- 新增“设备自动睡眠”设置，默认 5 分钟，可输入 1～1440 分钟；保存后通过蓝牙同步，重连时重新下发。配套固件将设置持久保存，重启和唤醒后仍然有效。
- 设备屏幕顶部第二行常驻显示当前运行的固件版本，例如 `FW 0.4.1`，无需连接电脑；较长版本号滚动显示。
- 保留已有自定义按键、快捷键录制及语音识别功能。

## 使用说明

退出旧版客户端后，安装 MSI，或解压便携 ZIP 后运行 `VoiceStick.exe`。已有配对、API 配置和按键映射继续使用；包内不包含个人配置或密钥。

本次正式发布的客户端和配套固件版本均为 `0.4.1`。睡眠配置需要同时使用新版客户端及固件；原版 0.4.0 固件不支持该指令。设备上的版本读取自实际运行固件的应用元数据，与客户端收到的版本一致。

## 下载文件

- `VoiceStick_0.4.1_zh-CN_custom-buttons_x64.msi`：Windows x64 安装版。
- `VoiceStick_0.4.1_zh-CN_custom-buttons_x64.zip`：Windows x64 便携版。
- `voicestick-firmware-sticks3-ota-0.4.1.bin`：用于 BLE OTA 的应用镜像。
- `voicestick-firmware-sticks3-merged-0.4.1.bin`：用于 USB 刷写的合并镜像，起始地址 `0x0`。
- `manifest.json` 和 `SHA256SUMS.txt`：固件下载清单及文件校验值。

## 验证范围

Windows x64 构建及 4 项本地测试通过；覆盖配置默认值、保存读取、非法输入、重连同步，以及已有按键和语音交互。StickS3 固件通过 ESP-IDF 5.5.2 编译与镜像校验。相同功能的开发构建已在 VS-5614 上通过 BLE OTA 刷入，确认重启、版本上报及客户端按键配置同步。macOS、Linux 的睡眠配置代码已同步，本次未提供对应平台的构建产物。
