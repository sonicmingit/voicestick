# VoiceStick 网站

VoiceStick 首页与 Sparkle/WinSparkle appcast 更新源的 Vue + Vite 源码。网站使用 `vue-i18n` 支持简体中文和英文；浏览器语言以 `zh` 开头时自动选择中文。

本仓库建议使用的 GitHub Pages 地址：

```text
https://78.github.io/voicestick/
```

macOS 和 Windows 应用读取生成后位于网站根目录的 appcast：

```text
https://78.github.io/voicestick/appcast.xml
```

## 发布流程

1. 首次发布前生成 Sparkle 密钥，私钥不要提交到 Git：

   ```bash
   cd desktop/macos
   swift package resolve
   find .build -name generate_keys -type f -perm -111 -print -quit
   .build/artifacts/sparkle/Sparkle/bin/generate_keys --account voicestick
   ```

2. 构建发布版本前，将公钥传入应用：

   ```bash
   SPARKLE_PUBLIC_ED_KEY="..." scripts/build-macos.sh --release
   ```

3. 创建 DMG：

   ```bash
   scripts/make-dmg.sh
   ```

4. 将以下文件上传到 GitHub Release `v<version>`：

   ```text
   build/VoiceStick-<version>.dmg
   build/VoiceStick-<version>.zip
   ```

5. 更新 `website/public/appcast.xml`：

   - `url`：GitHub Release 中 ZIP 文件的地址，此处使用 ZIP 包。
   - `sparkle:edSignature`：`build/VoiceStick-<version>.signature` 中的内容。
   - `length`：通过 `wc -c build/VoiceStick-<version>.zip` 获取的字节大小。

首页下载区直接链接到当前版本的 macOS DMG 和 Windows MSI。请让 `website/package.json` 与最新公开发布版本保持一致，确保下载链接和固件备用地址指向正确版本。浏览器烧录工具从 `VITE_FIRMWARE_MANIFEST_URL` 读取固件清单，并使用其中的 `merged_url`；如果清单加载失败，则回退到根据 `website/package.json` 生成的对应版本合并固件地址。

## 开发

```bash
cd website
npm install
npm run dev
```

## 构建

```bash
cd website
npm run build
```

生成的 `dist/` 目录部署到 GitHub Pages。`public/appcast.xml` 会复制为 `dist/appcast.xml`。固件清单本身托管在 OSS 上。

## GitHub Actions 工作流

- `.github/workflows/release.yml` 由 `v*` 标签或手动操作触发。它构建 macOS 应用，为 DMG 签名并公证，将 DMG、ZIP 和签名上传到对应的 GitHub Release，构建带版本号的 OTA 镜像和合并固件镜像，将固件清单发布到 OSS，重写 `public/appcast.xml`，构建 Vue 网站，并将 `website/dist` 部署到 GitHub Pages。
- `scripts/build-msi.bat` 在插有 USB 签名密钥的本地 Windows 签名机器上运行。生成的 `VoiceStick_<version>.msi` 需上传到对应的 GitHub Release。
- `.github/workflows/deploy-website.yml` 在 `main` 分支的 `website/**` 发生变更时触发，也可在上传 Windows MSI 后手动运行。部署前，它读取当前线上 appcast 和最新 GitHub Release，根据最新的 ZIP、签名及可选 MSI 附件重新生成 `public/appcast.xml`。如果最新发布中还没有 Windows MSI，则保留上一个 Windows 更新条目。

发布构建需要配置以下仓库机密：

```text
SPARKLE_PUBLIC_ED_KEY
SPARKLE_PRIVATE_ED_KEY
MACOS_CERTIFICATE_P12
MACOS_CERTIFICATE_PASSWORD
APPLE_ID
APPLE_TEAM_ID
APPLE_APP_SPECIFIC_PASSWORD
```
