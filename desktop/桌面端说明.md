# VoiceStick 桌面端

桌面客户端按平台组织。现有 macOS 应用继续使用 Swift 包，Windows 和 Linux 则分别使用独立的 C++ 工作目录。

```text
desktop/
  macos/      # 现有的 Swift/AppKit 菜单栏应用
  windows/    # Windows C++ 实现工作目录
  linux/      # Linux C++ 实现工作目录
```

目前尚未引入共享代码。待 Windows 和 Linux 实现中出现明确的公共部分后，再提取共用的 C++ 代码。

平台说明：[macOS 构建](../项目说明.md#macos-桌面端构建)、[Windows](windows/Windows使用说明.md)、[Linux](linux/Linux使用说明.md)。API 接入见 [配置与版本选择指南](../docs/API配置与版本选择指南.md)。
